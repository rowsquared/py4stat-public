## Sample Variable Names

When creating fake datasets, use these realistic variable names:

### Demographic

- `hh_id` — Household ID
- `person_id` — Person ID
- `province` — Province code (NTH, STH, etc.)
- `district` — District name
- `urban_rural` — Urban/Rural indicator
- `age` — Age in years
- `sex` — Male/Female
- `education_level` — Highest education completed
- `marital_status` — Marital status

### Economic

- `employment_status` — Employed/Unemployed/Inactive
- `occupation_code` — ISCO occupation code
- `industry_code` — ISIC industry code
- `monthly_income` — Income in DKW
- `hours_worked` — Weekly hours worked

### Geographic

- `latitude` / `longitude`
- `ea_code` — Enumeration Area code
- `admin1` / `admin2` / `admin3` — Administrative levels
